# CaterBook - Premium Catering Management System

CaterBook is a sophisticated, high-performance web application designed for elite catering businesses to manage operations, bookings, and client relationships with cinematic elegance and data-driven precision.

## ✨ Core Features

### 🏢 Administrative Powerhouse
- **Dynamic Dashboard**: Real-time business intelligence with live-updating statistics.
- **Advanced Analytics**: In-depth reports on revenue, occupancy rates, and client satisfaction using **Chart.js** visualizations.
- **Bespoke Booking Management**: End-to-end control over client event requests and scheduling.
- **Menu & Package Engine**: Create and manage multi-tier event packages (Classic, Gold, Platinum) and a dynamic culinary catalog with image upload support.
- **Inventory & Staff Tracking**: Monitor supplies and manage catering teams from a centralized hub.
- **Real-Time Communication**: Integrated messaging system for direct interaction with clients.
- **Financial Localization**: Professional revenue tracking localized to Indian Rupees (₹).

### 🍽️ Premium Client Experience
- **Cinematic Landing Page**: Immersive 3D hero section with video backgrounds and interactive culinary scenes.
- **Intuitive Booking Wizard**: Streamlined event booking process for weddings, corporate galas, and private celebrations.
- **Interactive Menu Gallery**: High-performance marquee displays for browsing culinary offerings.
- **Personalized Portal**: Track booking status, view personal event galleries, and manage profiles.
- **Responsive Luxury Design**: Seamless experience across mobile, tablet, and desktop with persistent dark/light mode support.

## 🚀 Quick Setup

1. **Prerequisites**: Ensure you have XAMPP/WAMP or a LAMP stack installed (PHP 7.4+ required).
2. **Installation**:
   - Clone this repository into your `htdocs` or `www` directory.
   - Import the database schema (locate `setup.php` or your `.sql` file).
   - Configure database credentials in `config.php`.
3. **Database Setup**:
   ```php
   // config.php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'catering_db');
   define('DB_USER', 'root');
   define('DB_PASS', '');
   ```
4. **Launch**: Access the application via `http://localhost/Catering_Management_System/index.php`.
